بناء APK بدون تثبيت Android Studio على جهازك

تم تجهيز GitHub Actions لبناء نسخة APK تلقائيًا على خادم GitHub.

الخطوات المطلوبة مرة واحدة:
1) أنشئ مستودعًا جديدًا على GitHub.
2) ارفع ملفات هذا المشروع إلى المستودع (بما فيها مجلد .github).
3) افتح تبويب Actions في المستودع وفعّل Actions إن طُلب منك.
4) شغّل workflow باسم Build StudyTask APK من زر Run workflow، أو ادفع الملفات إلى main.
5) بعد انتهاء البناء، افتح نتيجة التشغيل وانزل إلى Artifacts ثم حمّل StudyTask-debug-apk.zip. داخله app-debug.apk.

ملاحظات:
- هذا يبني APK تجريبيًا (debug) وليس نسخة متجر موقعة.
- لا يحتاج Android Studio على جهازك، لكن يحتاج حساب GitHub ورفع ملفات المشروع إليه.
- ميزة الاستيراد الحالية تعرض PDF/الصورة وتتيح إدخال الجدول ومراجعته يدويًا؛ لا يوجد استخراج تلقائي للمحاضرات من الصورة/PDF بعد.
