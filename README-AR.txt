StudyTask - نسخة معدّلة للموبايل

التعديلات: تحسين العرض على شاشة الموبايل، زر مسح كل الجدول مع تأكيد، إضافة تاريخ اختياري لكل موعد، وإعادة ضبط علامات إنجاز الكويز والواجب والحضور كل 14 يومًا مع الاحتفاظ بأسماء المحاضرات والسكاشن.

هذا ملف مصدر وليس APK جاهزًا. يلزم بناء APK من خلال Android Studio/Capacitor. البيانات محلية ولا توجد مزامنة سحابية مفعلة. احتفظ بنسخة احتياطية قبل التثبيت.


تحديث استيراد الجدول: تمت إضافة قسم داخل التطبيق لاختيار PDF/صورة، اختيار المجموعة A1-A20 والأسبوع الفردي/الزوجي، إدخال الحصص ومراجعتها وتعديلها قبل حفظها في جدول التطبيق. لا يوجد استخراج تلقائي OCR في هذه النسخة؛ يجب إدخال تفاصيل الحصص يدويًا بعد معاينة الملف. بناء APK يحتاج مجلد Android واعتمادات Capacitor/Android المتوفرة محليًا أو اتصال إنترنت لتجهيزها.

لإنشاء APK دون Android Studio، راجع BUILD-APK-AR.txt. أُضيف workflow للبناء السحابي عبر GitHub Actions.
